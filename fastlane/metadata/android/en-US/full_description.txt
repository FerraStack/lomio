<p>Lomio runs open language models on your phone. Pick a starter model during first-run setup, download models from Hugging Face (or import your own GGUF files), load one, and chat. Everything happens on the device: no account, no analytics, no cloud. After the download, chats work offline.</p>

<p><b>Chat</b></p>
<ul>
<li>Streaming replies with Markdown, tables and highlighted code with a Copy button</li>
<li>A collapsible reasoning block for thinking models, with a Think switch</li>
<li>Stop, regenerate (replies are kept as versions), edit and resend</li>
<li>Images: ask vision models about photos you pick (no storage permission needed)</li>
<li>A context meter; when a chat gets long, summarize it and continue</li>
<li>History with search, pins and export to Markdown or JSON</li>
<li>Quick Settings tile ("Ask Lomio"), app shortcuts, and an adaptive layout with a persistent drawer on tablets and foldables</li>
</ul>

<p><b>Models</b></p>
<ul>
<li>Guided onboarding that picks a starter model suited to your phone's RAM</li>
<li>Search Hugging Face for GGUF models, including multi-part split GGUF and vision models with their projector</li>
<li>Resumable downloads, verified against each file's SHA-256 checksum</li>
<li>A memory check before each load warns when a model may not fit your phone</li>
<li>Settings per model and per chat: system prompt, sampling, context size, chat template</li>
<li>A storage screen shows what takes space and cleans up unused models or leftovers</li>
</ul>

<p><b>Local API server &amp; Engine</b></p>
<ul>
<li>Optional OpenAI-compatible HTTP server (off by default) for Termux, scripts and other apps on your phone or Wi-Fi (with an API key)</li>
<li>Powered by llama.cpp with CPU code tuned for each ARM generation and on-disk prompt caching for fast reopening of long chats</li>
<li>Experimental OpenCL GPU acceleration for Snapdragon (Adreno) phones and a built-in speed benchmark</li>
</ul>

<p>Models are large: plan 0.5–3 GB of storage per model and a phone with 6 GB of RAM or more for the bigger ones. Lomio itself contains no model.</p>

<p>Lomio is open source (Apache-2.0).</p>
