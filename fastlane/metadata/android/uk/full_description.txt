<p>Lomio запускає відкриті мовні моделі просто на телефоні. Завантажте модель з Hugging Face (або імпортуйте файл GGUF), увімкніть її та спілкуйтеся. Усе працює на пристрої: без акаунта, без аналітики, без хмари. Після завантаження чати працюють офлайн.</p>

<p><b>Чат</b></p>
<ul>
<li>Відповіді в реальному часі з Markdown, таблицями та підсвічуванням коду з кнопкою «Копіювати»</li>
<li>Згортуваний блок міркувань для «мислячих» моделей і перемикач «Думати»</li>
<li>Зупинка, повторна генерація (відповіді зберігаються як версії), редагування й повторне надсилання</li>
<li>Зображення: питайте моделі із зором про вибрані фото (дозвіл на доступ до файлів не потрібен)</li>
<li>Індикатор заповнення контексту; довгий чат можна стиснути до короткого підсумку й продовжити</li>
<li>Історія з пошуком, закріпленням та експортом у Markdown або JSON</li>
</ul>

<p><b>Моделі</b></p>
<ul>
<li>Пошук моделей GGUF на Hugging Face або короткий список рекомендованих для початку</li>
<li>Докачування після обриву та перевірка контрольної суми файлу</li>
<li>Перед завантаженням перевіряється, чи вистачить пам'яті телефона</li>
<li>Налаштування для моделі й для чату: системний промпт, семплінг, розмір контексту, шаблон чату</li>
<li>Екран «Сховище» показує, що займає місце, і допомагає його звільнити</li>
</ul>

<p><b>Рушій</b></p>
<p>Lomio працює на llama.cpp з кодом для CPU, оптимізованим під кожне покоління ARM. Довгий чат відкривається швидко: його стан зберігається на диску. Прискорення на GPU для телефонів Snapdragon (Adreno) доступне як експеримент. Вбудований тест вимірює швидкість на вашому телефоні.</p>

<p>Моделі великі: розраховуйте на 0,5–3 ГБ пам'яті на модель і телефон із 6 ГБ оперативної пам'яті або більше для великих моделей. У самому Lomio моделей немає.</p>
